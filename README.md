# LinguaSchool

Учебная защищённая ИС школы иностранных языков на Flask и PostgreSQL. Включены исходный код, интерфейс, тесты, генератор 5000 записей, проектная документация, материалы документации и речь. Локальный быстрый запуск использует SQLite; вариант по методичке — PostgreSQL через Docker.

## Быстрый запуск в Windows

Установите Python 3.12 или новее. Распакуйте архив и откройте терминал в папке LinguaSchool:

```powershell
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python configure.py
.venv\Scripts\python -m flask --app app init-db
.venv\Scripts\python -m flask --app app seed
.venv\Scripts\python -m flask --app app run
```

Откройте http://127.0.0.1:5000. Команда seed показывает четыре случайных пароля ОДИН РАЗ: сохраните их. Аккаунты: admin@demo.local, teacher@demo.local, student@demo.local, student2@demo.local. Первый ученик записан на курсы, второй нужен для проверки отказа в доступе. Повторный seed в непустой БД запрещён. Даты занятий и дедлайны формируются относительно запуска, часовой пояс UTC.

START.bat автоматизирует установку и старт; seed при первом запуске выполните отдельно в другом терминале, как указано в окне. Регистрация создаёт только ученика. Администратор записывает его на курс через «Управление».

## PostgreSQL через Docker

Нужен Docker Desktop с Linux-контейнерами. Сначала выполните configure.py, затем:

```powershell
docker compose up -d --build
docker compose exec web flask --app app init-db
docker compose exec web flask --app app seed
```

Откройте http://127.0.0.1:8000. Остановка: `docker compose down`. Данные сохраняются в томе pgdata; не удаляйте его без резервной копии. Пароль PostgreSQL берётся из .env, порт БД наружу не опубликован. Compose автоматически заменяет SQLite URL на PostgreSQL URL.

## Проверки

```powershell
.venv\Scripts\python -m unittest discover -s tests -v
```

Тесты используют отдельную БД в памяти и не удаляют рабочие данные. Фактический результат сборочной проверки — docs/VALIDATION.md. Для проверки именно PostgreSQL запустите Docker-сценарий и пройдите docs/TEST_PLAN.md. Отдельный прогон на PostgreSQL 18.6 выполнен 6 ноября 2026 года, все 13 тестов прошли. Протокол — docs/postgresql-test-results.txt. Запуск Docker Compose отдельно не подтверждён.

## Сценарий демонстрации

1. Ученик: войти → пройти тест → открыть кабинет → открыть материал → отправить домашнюю работу.
2. Преподаватель: открыть курс → задание → выставить оценку и комментарий.
3. Ученик: увидеть оценку. Второй ученик: открыть /course/1 и получить 403.
4. Администратор: назначить курс новому ученику, создать курс и занятие, открыть журнал и скачать CSV.

## Состав

- app.py — модели, серверные проверки, маршруты и команды БД.
- templates и static — адаптивный веб-клиент без внешних CDN.
- tests — проверка основных сценариев и защиты.
- docs/REPORT.md — основа пояснительной записки из трёх глав.
- docs/ARCHITECTURE.md — ER-диаграмма, матрица доступа, модель угроз.
- docs/DATALENS.md и analytics/ — схема аналитики и CSV из 5000 синтетических попыток.
- docs/SLIDES.md — содержание 9 слайдов для переноса в презентацию.
- docs/SPEECH.md — речь для защиты.

## Безопасная конфигурация

Пароли — Argon2id, телефон — Fernet (аутентифицированное симметричное шифрование), сессия — случайный серверный идентификатор плюс подписанная cookie. .env и БД не включаются в Git. Потеря FIELD_KEY делает телефоны недоступными: резервируйте ключ отдельно от дампа БД. Email хранится открыто для входа; имя и email тоже персональные данные, доступ к БД должен быть ограничен. Паспортные данные не собираются.

Локальный HTTP требует COOKIE_SECURE=0. При развёртывании через HTTPS задайте COOKIE_SECURE=1 и настройте TLS на обратном прокси. Не включайте debug. Ограничитель входа глобальный (30 ошибок в минуту на всю систему), пригоден для демонстрации; для эксплуатации нужен отдельный лимитер по аккаунтам и источникам, мониторинг и восстановление паролей. Удаляйте истёкшие серверные сессии по расписанию. Все материалы представлены текстом; видео-DRM и файловый обмен не входят в этот проект.
