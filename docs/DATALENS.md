# Аналитика Yandex DataLens

В воркбуке LinguaSchool сохранён дашборд «LinguaSchool — результаты тестирования».
Ссылка на воркбук https://datalens.ru/workbooks/ozu7tu5lsy327

Источник — файл attempts.csv с 5000 синтетических попыток.
На панели показаны число попыток по уровням A1–B2, динамика по неделям и сводная таблица.
Контрольные показатели — 5000 попыток и средний балл 50,80.
Снимок дашборда находится в docs/screenshots/11-DataLens.png.

CSV содержит attempt_id, score, level, date и synthetic.
Приложение предоставляет администратору актуальную выгрузку по /analytics.csv.
Для обновления панели нужно загрузить новую выгрузку и сверить число попыток и средний балл.
Селекторы периода и уровня могут быть добавлены при дальнейшем развитии.
