# Материалы для защиты LinguaSchool

[Пояснительная записка Word](LinguaSchool-report.docx)

[Презентация PowerPoint](LinguaSchool-presentation.pptx)

Автор — Пожидаев Никита Сергеевич, группа ИБ-52Б.
Руководитель — Марухленко Анатолий Леонидович.

Записка содержит три главы и содержание с переходами к разделам. Аналитика DataLens включена в практическую главу. Презентация содержит 10 слайдов. В материалах использованы реальные снимки интерфейса и дашборда.

На титульном листе осталось заполнить образовательную организацию, кафедру или отделение и город.
Перед сдачей проверьте разметку страниц в Word. Объём 30–50 страниц требует проверки, поскольку преобразование для визуальной проверки в среде подготовки было недоступно.

Текст доклада находится в [SPEECH.md](../SPEECH.md). Протокол PostgreSQL находится в [postgresql-test-results.txt](../postgresql-test-results.txt).
REPORT.md и SLIDES.md в родительской папке содержат ранние текстовые заготовки. Для защиты используйте DOCX и PPTX из этой папки.
